## Powers

## Prompts

These will expand as functionality is added as part of the proof of concept.

For example, if we add a skill, then we should add a prompt showing how to use that skill.

## Scripts

This will likely be removed in the future from the highest level.

The files that are in scripts/ will be tapered down to only what is necessary.

## Shared Kernels

Named frameworks and models reused across artifacts, such as TIME. Each one is defined once and referenced everywhere else.

This will likely grow exponentially to support the Agents.

## Skills

These will be Markdown files that dictate abilities the Agents have

## Steering

These will be Markdown files that dictate how the Agents behave with skills.

## Workflows

Ordered combinations of skills that one or more agents run to produce work.

These also could be multi-agent combinations that are run to produce work.
