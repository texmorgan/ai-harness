# Naming

- Artifact ids are lowercase kebab-case and match the file name without `.md`.
- Ids are unique across `src/`. Check before adding one.
- Use the words in `src/context/glossary.md`. If a term is missing from the glossary, add it there rather than inventing a synonym.
- Parameter names are snake_case.
